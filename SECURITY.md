# Security

Please report security problems privately to the repository owner before opening a public issue.

Do not attach account credentials, private messages, authentication tokens, complete game files or unredacted diagnostics to a public report. Include the Manager version, the first twelve characters of its displayed build hash, the game version, the mod name and the smallest relevant log section.

The public repository and release checks must never contain private signing keys, game executables, extracted proprietary game source, player state or credentials. External `.semod` files are keyless but remain subject to strict inventory, path, content and SHA-256 validation.
